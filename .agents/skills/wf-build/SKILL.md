# 구현과 시험

요구마다 입력·관찰 장소·기대값을 먼저 정한다. 그 결과를 어기면 실패하는 검사를 실행하고, 실패를 고칠 만큼 구현한다. 기존 보장과 처음·반복·재개·연결된 사용 흐름도 확인한다. 검사가 구현과 같은 잘못된 가정을 따르지 않는지 원문으로 대조한다.

새 사용자 선택이 생기면 `wf-ask`로 돌아간다. 확인 명령·출력·대상 상태는 `wf-ask/map.md`의 기록 도구로 보존한다. 작은 단일 작업은 직접 실행 증거를 대화에 남겨도 된다.

## 끝 조건

원래 실패와 연결된 기존 검사가 통과하고, 실제 결과를 `wf-verify`에서 원문과 대조할 수 있다. 명령을 적은 것과 실행한 것은 다르다.
