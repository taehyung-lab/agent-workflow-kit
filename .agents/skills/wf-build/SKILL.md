# 구현과 시험

AGENTS.md의 요구 확인을 마치고 입력·관찰 위치·기대값과 출처를 인계받는다. 결정이나 독립 읽기 대조가 남으면 요구 확인으로 돌아간다.

실제 사용 경로에서 그 기대값을 어기는 실패를 재현하고 원인을 고친다. 같은 입력과 처음 고정한 기대값으로 다시 실행한다. 연결된 기존 동작과 처음·반복·재개 경로도 확인한다. 구현에 맞춰 최초 검증표를 교체하지 않는다. 측정 방법이 틀렸으면 당시 실패와 근거를 보존하고 측정 방법을 고친다. 새 사용자 결정으로 기대 결과가 바뀌면 원문과 새 판을 기록한다.

## 끝 조건

실행한 명령·출력·대상 상태를 보존해 `wf-verify`가 원문과 대조할 수 있다. 대표 기록은 `wf-ask/map.md`의 검사 도구를 쓴다.
