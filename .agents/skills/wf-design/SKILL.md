# 조건과 설계
1. 관련 원문·사용자 결정·계약과 현재 입력→소유자→소비자를 조사한다. 특이한 제약의 이유와 사실·추측을 구분한다.
2. 질문에는 확인한 근거·추천·답에 따라 달라지는 조건을 붙인다. 사용자가 이미 명시한 변경은 다시 묻지 않는다.
3. 새 결과와 영향받는 [기존] 조건에 번호를 붙인다. 실패·취소를 포함한 입력·관찰 장소·기대 결과·환경을 정한다.
4. 바뀐 값의 소유자·소비자와 가장 단순한 변경 위치·이유를 정한다. 새 검사의 반례와 실환경 필요 여부도 정한다.
5. 재사용할 사용자 결정은 지정 정본에 남긴다. 인계가 필요하면 work-template.md로 담당자·한도·미정·필요한 검증을 전달한다.
