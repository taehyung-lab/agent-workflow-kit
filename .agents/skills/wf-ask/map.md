# 대표 작업 기록

AGENTS.md 「작업 경로」에서 대표 기록이 필요한 작업은 기록 하나를 쓴다. 여러 저장소 작업은 홈의 `work/<작업명>`, 단일 작업은 해당 저장소의 같은 경로다. 원문과 후속 답은 그대로 파일로 받아 `record`에 넘긴다. 도구는 원문을 보존하고 읽기용 work.md를 만든다. 생성된 지도를 손으로 고치지 않는다.

[작업 도구 사용법](../wf-verify/work.md)의 `record → check → review`를 따른다. 요구가 바뀌면 새 원문과 전체 현재 계획을 기록한다. 이전 원문·계획은 지우지 않는다. 원문에서 요구(입력→관찰 장소→기대)를 해석한 책임은 에이전트에게 있고 도구가 승인을 판독하지 않는다.

기존 수동 지도는 과거 증거로 보존한다. 새 작업의 원문·현재 계획을 옮길 때 사용자의 글과 해석을 분리한다. 팀에 공유할 제품 결정은 해당 저장소에 남기고 대표 원문을 출처로 가리킨다.
