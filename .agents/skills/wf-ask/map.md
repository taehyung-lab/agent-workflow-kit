# 대표 작업 기록

AGENTS.md 「작업 경로」에서 대표 기록이 필요한 작업은 기록 하나를 쓴다. 여러 저장소 작업은 홈의 `work/<작업명>`, 단일 작업은 해당 저장소의 같은 경로다. 현재 계획에는 이번에 검사·검토까지 끝낼 요구와 실제 확인 명령을 함께 둔다. 이후 작업은 전체 로드맵에 남기고 현재 작업의 미정 요구로 섞지 않는다. 원문과 후속 답은 이 기록에 그대로 보존해 후속 작업도 같은 출처를 참조한다. 도구가 만든 work.md는 읽기용이다.

[작업 도구 사용법](../wf-verify/work.md)의 `record → check → review`를 따른다. 교정 작업의 실행 범위는 실패 재현·원인 교체·수정본 재검증까지 포함해 도구·권한·시간·횟수·비용 한도와 중단 조건을 정한다. 그 범위 안의 후속 실행을 이어 가고 한도 확대나 새 사용자 결과는 먼저 묻는다. 요구가 바뀌면 새 원문과 전체 현재 계획을 기록하며 이전 기록은 보존한다. 원문에서 기대값을 해석한 책임은 에이전트에게 있고 도구가 승인을 추측하지 않는다. 보고에는 현재 끝낸 작업과 전체 목표의 남은 부분을 함께 표시한다.

기존 수동 지도는 과거 증거로 보존한다. 새 작업의 원문·현재 계획을 옮길 때 사용자의 글과 해석을 분리한다. 팀에 공유할 제품 결정은 해당 저장소에 남기고 대표 원문을 출처로 가리킨다.
