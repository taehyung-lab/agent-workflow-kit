# 독립 판정
1. 구현하지 않은 검증자가 맡는다. 구현 기록은 길잡이로 쓰고, 확정된 조건을 원문 근거와 대조한다. 조건 밖 누락을 발견하면 판정하지 않고 설계로 돌려보낸다.
2. 대상 버전·환경을 맞춰 조건별 실제 결과와 새 검사의 반례 판별력을 확인한다. 기준 변경 항목은 근거와 판별력을 다시 본다.
3. 판정 중 기준·제품 코드를 바꾸지 않는다. 증거 재사용은 변경 영향과 환경이 여전히 유효한 이유가 있을 때만 한다.
4. 실패는 기대·실제·재현과 확인된 원인을 붙여 소유자에게 돌리고, 수정 뒤 실패와 영향을 다시 확인한다. 원인 미상은 추측으로 닫지 않는다.
5. 조건별 판정·근거·남은 행동을 전체 담당자에게 넘긴다.
