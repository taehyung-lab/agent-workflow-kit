# 독립 판정과 교정
1. 구현하지 않은 검증자가 맡는다. 구현 기록은 길잡이로 쓰고 원문·현재 소비 경로에서 기대값과 조건 누락을 먼저 확인한다.
2. 대상 버전·환경을 맞춰 조건별 실제 결과와 새 검사의 반례 판별력을 확인한다. 기준 변경 항목은 근거와 판별력을 다시 본다.
3. 판정 중 기준·제품 코드를 바꾸지 않는다. 증거 재사용은 변경 영향과 환경이 여전히 유효한 이유가 있을 때만 한다.
4. 실패의 기대·실제·재현과 확인된 원인을 소유자에게 돌린다. 원인 미상은 추측으로 닫지 않으며 실패와 수정 영향을 재확인한다.
5. 구현은 코드, 틀린 통과는 검사, 탐색 누락은 description, 기계적 실수는 자동화 등 실제 원인 소유물을 교정한다.
6. 재사용 문서는 기존 판단부터 교정하고 효과는 실제 재사용 범위만 주장한다. 조건별 판정·근거·남은 행동을 전체 담당자에게 넘긴다.
