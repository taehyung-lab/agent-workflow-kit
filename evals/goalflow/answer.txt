1. 옛 신청 기록: 기존 행과 번호는 지우거나 바꾸지 않습니다. 같은 요청 ID 로 저장된 행이 여러 개면 그 요청의 결과는 가장 최근 행(번호가 가장 큰 행) 하나로 봅니다. 조회는 그 행을 확정으로 안내하고, 재시도도 그 행과 회원·회차가 같으면 그 번호를 그대로 안내하며, 다르면 요청 충돌로 거절합니다. 이미 정원을 넘겨 저장된 기존 행도 확정으로 두고 새 신청의 정원 계산에 포함합니다.
2. 같은 회원의 재신청: 이미 확정된 회원이 같은 회차를 다른 요청 ID 로 다시 신청하면 새 행을 만들지 않고, 기존 확정(그 회원·회차의 가장 최근 행)의 번호와 회차를 '신청 완료'로 안내합니다. 같은 요청 ID 가 이미 있으면 1번 규칙이 먼저입니다. 다른 회차 신청은 새 신청입니다.
3. 새 요청 ID 연결: 2번처럼 새 요청 ID 로 기존 확정을 안내했으면, 그 새 요청 ID 도 기존 확정에 연결해 저장합니다(신청 행은 늘리지 않습니다). 그 ID 로 조회하면 기존 번호·회차가 '신청 완료'로 나오고, 그 ID 를 다른 회원·회차에 쓰면 요청 충돌로 거절합니다.
