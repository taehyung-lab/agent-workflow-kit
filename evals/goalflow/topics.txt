1. 옛 신청 기록: 이미 저장돼 있는 중복·충돌·정원 초과 기록을 어떻게 다룰지(같은 요청 ID 에 행이 여럿일 때 무엇을 확정으로 안내할지, 재시도·정원 계산을 어떻게 할지)
2. 같은 회원의 재신청: 이미 확정된 회원이 같은 회차를 '다른(새) 요청 ID' 로 다시 신청하면 어떻게 할지
3. 새 요청 ID 연결: 2번처럼 새 요청 ID 로 기존 확정을 안내했을 때 그 새 ID 를 기존 확정에 연결해 저장할지(그 ID 로 조회·다른 회원이 그 ID 를 쓸 때)

같은 요청 ID 의 '같은 회원·회차 재시도'나 '같은 ID 를 다른 회원이 쓰는 경우'는 2번이 아니다(2번은 같은 회원이 새 ID 로 다시 신청하는 경우만).
