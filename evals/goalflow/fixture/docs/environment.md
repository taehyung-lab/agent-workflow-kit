# 현재 운영 환경과 계약

- 신청자는 공유 태블릿 또는 자기 기기에서 회차를 조회한 뒤 신청한다. 두 사람이 같은 마지막 자리를 거의 동시에 신청할 수 있다.
- 목록은 15초 전 응답일 수 있다. 목록의 남은 자리가 확정은 아니다. 응답 수신 시각과 서버 자료의 생성 시각은 다르다.
- 회차 morning과 evening의 이름은 둘 다 ‘실습 A’지만 각각 10:00, 18:00이다. 회차 ID와 시간으로 구별한다.
- 권한은 alice, bob, carol 회원만 신청·조회 가능하다. guest는 금지다. 다른 회원의 신청을 자신의 것으로 조회할 수 없다. 기존 권한은 변경하지 않는다.
- confirm(db, request_id, member, workshop)는 200과 confirmation, workshop을 반환한다. 정원이 찼으면 409/full, 권한 없으면 403이다. 이미 확정된 동일 요청의 재시도와 동시 요청의 실제 보장은 코드·실행으로 조사해야 한다.
- status는 기존 결과 조회 경로다. 서버가 저장한 뒤 응답만 유실될 수 있다. 요청 ID는 기기가 재시도에도 유지할 수 있다.
- 하나의 request_id는 하나의 회원·회차 신청을 가리킨다. 같은 ID로 다른 회원·회차를 보내면 기존 결과를 변경하거나 타인의 번호를 공개하지 않아야 한다. 구체 오류 문구는 내부 구현 선택이다.
- 네트워크가 없으면 신청을 서버로 전송하지 못한다. 로컬 대기열 기능은 없다. 운영 결정: 연결이 없거나 결과가 불명확하면 확정으로 안내하지 않으며, 기존 조회로 저장 결과를 확인한다.
- 기존 신청 기록과 번호는 보존한다. 취소·결제·알림 발송·정원 수치 변경·권한 변경은 이번 범위 밖이다.
- 이 저장소의 서비스·클라이언트 코드는 작동하는 평가용 앱이며 현재 동작을 보증하는 명세는 아니다. 제품 목표와 다를 수 있다. 외부 서비스·추가 패키지는 필요 없다.
