# 운영 규칙

- `data.json` 은 지금 운영 중인 주문 자료다. 주문 번호와 이미 들어 있는 주문의 내용은 지우거나 바꾸지 않는다. 자료 형식을 바꾸더라도 지금 들어 있는 주문은 그대로 읽혀야 한다.
- 배송비는 주문마다 3,000원이다.
- 결제가 끝난 주문(`paid`)은 고칠 수 없고, 영수증의 금액도 결제한 뒤로는 바뀌지 않는다. 회계 담당자가 결제된 영수증의 `total` 로 입금을 맞춰 본다.
- 영수증(`receipt`)의 JSON 은 회계 프로그램이 읽는다. 지금 있는 키(`id`·`customer`·`status`·`goods`·`shipping`·`total`)의 뜻과 값의 형식(금액은 원 단위 정수)은 유지한다. 키를 더하는 것은 괜찮다.
  - `goods`: 상품 가격의 합. `shipping`: 배송비. `total`: 고객이 실제로 낼 금액.
- 검사나 실험은 `ORDERS_DATA` 로 다른 파일을 지정해서 한다.
