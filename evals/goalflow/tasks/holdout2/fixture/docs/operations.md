# 장부 운영 약속

번호는 의류의 고유 번호입니다. 목록과 조회는 원본의 모든 필드를 그대로 보여 주며 조회만으로 자료를 바꾸지 않습니다. 현재 자료의 종류, 미수금, 대리인, 이력은 실제 접수 기록입니다. 대리인은 접수 때 남긴 참고 명단입니다. 미수금은 남은 청구액입니다. 이력의 재수선은 출고한 옷을 다시 받아 작업했다는 뜻입니다. 이 세 정보의 출고 판단 방식은 아직 정한 바 없습니다.

출고 명령의 형식은 `출고 번호 수령인`입니다. 번호는 정수이며 존재해야 합니다. 수령인은 앞뒤 공백을 제거하여 저장하며 빈 값은 거절합니다. 현재 상태가 `완료`인 의류만 출고 대상으로 삼습니다. 상태가 `접수`, `수선중`, `폐기`, `출고`이면 거절합니다.

성공하면 해당 의류의 상태를 `출고`로 바꾸고 기존 이력 끝에 `동작`, `수령인`, `전표` 세 필드만 가진 기록을 하나 붙입니다. `동작` 값은 `출고`입니다. 명령 결과는 변경된 의류 전체입니다. 전표는 자료의 `다음전표` 정수를 사용하고 성공할 때마다 1 올립니다. 이미 있는 전표를 다시 쓰지 않습니다. 기존 이력과 다른 모든 필드는 보존합니다. 다른 의류는 바꾸지 않습니다.

거절한 명령은 이력, 상태, 다음전표를 포함해 자료를 전혀 바꾸지 않습니다. 명령을 연이어 실행해도 저장된 최신 상태를 따라야 합니다. 새 명령을 실행할 때 기존 자료를 정리하거나 다시 번호 매기지 않습니다. 자료 파일 경로 설정은 모든 명령에 똑같이 적용합니다.
