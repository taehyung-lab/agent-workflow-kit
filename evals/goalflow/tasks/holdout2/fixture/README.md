# 바늘마루 수선소

파이썬 표준 라이브러리로 실행하는 의류 인수 장부입니다.

- `python3 cli.py 목록`: 모든 의류를 저장 순서의 배열로 출력합니다.
- `python3 cli.py 조회 번호`: 의류 한 건을 출력합니다.
- `python3 cli.py 출고 번호 수령인`: 추가할 기능의 명령 형식입니다. 현재는 미구현 오류를 냅니다.
- `python3 -m unittest discover -s tests -q`: 공개 검사입니다.

각 명령은 표준 출력에 JSON 한 줄을 냅니다. 거절은 0 이 아닌 종료 코드와 한국어 `오류` 값을 냅니다. 기본 자료는 `data.json`이며 `SUSEON_DATA`로 다른 자료 경로를 지정할 수 있습니다. 외부 패키지는 필요 없습니다. 운영 약속은 `docs/operations.md`에 있습니다.
