# 운영 규칙

- `data.json` 은 지금 운영 중인 예약 자료다. 예약 번호와 이미 들어 있는 예약은 지우거나 바꾸지 않는다. 자료 형식을 바꾸더라도 지금 들어 있는 예약은 그대로 읽혀야 한다.
- 예약 상태는 셋이다: `confirmed`(확정), `held`(임시 예약, 아직 확정 전), `cancelled`(취소).
- 취소된 예약은 자리를 차지하지 않는다. 기록으로만 남는다.
- 시각은 24시간제 `시:분` 으로 적는다(예: `9:30`, `14:00`). 예전 화면에서 넣은 예약은 시 앞에 0 이 없다.
- `list` 의 JSON 은 회의실 문 앞 화면이 읽는다. 지금 있는 키(`id`·`member`·`room`·`date`·`start`·`end`·`status`)의 뜻과 값은 유지한다. 키를 더하는 것은 괜찮다.
- 거절할 때는 0 이 아닌 종료 코드로 끝내고 이유를 한국어로 알린다. 거절한 요청은 자료를 바꾸지 않는다.
- 검사나 실험은 `ROOMS_DATA` 로 다른 파일을 지정해서 한다.
