# 라벨 작업 운영 약속

- 기존 시트 번호, 상태, 표본별 수량은 임의로 바꾸거나 지우지 않는다. 기존 자료도 계속 읽을 수 있어야 한다. new는 기존 번호와 겹치지 않는 번호로 빈 draft 시트를 만든다.
- catalog는 표본 배열, specimen은 표본 하나를 JSON으로 돌려준다. 표본의 공개 키 code, name, size, custody, retired의 뜻과 값은 유지한다. size는 normal 또는 large이며 custody는 owned 또는 loan이다. retired가 true인 표본은 새로 추가할 수 없다.
- list는 모든 시트 배열, show와 new/add/remove/seal은 시트 하나를 JSON으로 돌려준다. 시트의 공개 키 id, status, items, used를 유지한다. items의 각 항목은 공개 키 code, name, quantity를 갖는다. code는 표본 코드, name은 인쇄할 이름, quantity는 라벨 장수다. 이 키들은 유지한다. status는 draft 또는 printed다. 키 추가와 내부 저장 형식 변경은 가능하다.
- used는 지금 담긴 라벨이 차지하는 칸 수다. 일반은 한 장에 한 칸, 큰 라벨은 한 장에 두 칸이다. 기존 시트의 내용도 계산에 포함한다. draft의 이름은 현재 표본 이름을 표시한다.
- add는 양의 정수 수량만 받는다. 같은 표본을 다시 담으면 수량을 합친다. 12칸은 허용하며 12칸 초과 추가는 거절한다.
- remove도 양의 정수 수량만 받는다. 담긴 수량보다 많이 빼거나 없는 표본을 빼면 거절한다. 수량이 0이 되면 항목을 없앤다. 삭제한 칸은 다음 추가에서 즉시 다시 쓸 수 있다. 최종 내용이 같으면 추가·삭제 순서에 관계없이 used도 같다.
- 없는 시트·표본, 잘못된 수량, 용량 초과 등 거절한 명령은 모든 공개 조회 결과를 그대로 유지한다. 거절 후 올바른 명령으로 재시도할 수 있어야 한다.
- seal은 빈 시트를 거절하고, 내용이 있는 draft를 printed로 바꾼다. 새로 확정한 시트의 name은 확정 당시 값으로 고정한다. 이번 기능으로 확정한 시트에 seal을 반복해도 처음 확정한 것과 동일한 공개 값을 돌려준다. printed에는 add/remove를 거절한다.
- 프로그램 실행 사이에도 변경 사항을 저장한다. list/show는 저장 내용을 수정하지 않는다. 시트 배열과 items 배열의 정렬 순서는 약속하지 않는다.
- rename <코드> <새이름>은 학명 정정용 기존 명령이다. 해당 표본의 name만 바꾸고 표본 JSON을 반환한다. 다른 표본의 값과 모든 시트의 번호·상태·수량은 바꾸지 않는다.
